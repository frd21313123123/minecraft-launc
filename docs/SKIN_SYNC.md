# Синхронизация скинов

Лаунчер автоматически синхронизирует выбранный скин при входе на сервер:

1. Для ника или публичной PNG-ссылки готовится команда SkinsRestorer.
2. Локальный PNG один раз загружается через официальный API MineSkin,
   который использует страница Upload проекта SkinsRestorer, после чего
   результат кэшируется.
3. В клиентскую сборку NeoForge 1.21.1 устанавливается встроенный мод
   `MineLauncher Skin Sync`.
4. Через четыре секунды после входа мод отправляет команду серверному
   SkinsRestorer. Скин сохраняется в его базе и становится виден всем игрокам.

## Настройка сервера

- Установите актуальную версию SkinsRestorer.
- Разрешите игрокам команды скинов. При использовании LuckPerms:

  ```text
  /lp group default permission set skinsrestorer.player true
  ```

- Убедитесь, что сервер может подключаться по HTTPS к `api.mineskin.org`
  и сервисам Mojang.
- Если в лаунчере заполнен адрес сервера, команда отправляется только на этот
  адрес. Пустое поле разрешает синхронизацию на любом сервере.

Отдельный серверный мод не требуется: синхронизация использует публичную
команду и хранилище уже установленного SkinsRestorer.
