# Синхронизация скинов

MineLauncher использует один универсальный мод `MineLauncher Skin Sync` для
клиента, выделенного сервера и встроенного сервера одиночной игры.

1. В лаунчере выберите локальный PNG-скин 64×64 или укажите прямую публичную
   HTTPS-ссылку на такой PNG.
2. При запуске лаунчер проверит файл, скопирует его в папку игры и установит
   клиентскую копию мода.
3. После входа клиент отправит скин серверной части мода.
4. Сервер проверит PNG и разошлёт его всем подключённым игрокам с этим модом.

В одиночной игре используется тот же протокол через встроенный сервер
Minecraft, поэтому дополнительная настройка не нужна.

## Настройка сервера

- Используйте Minecraft 1.21.1, NeoForge 21.1.x и Java 21.
- Скопируйте файл
  `assets/minelauncher-skin-sync-neoforge-1.21.1.jar`
  в папку `mods` выделенного сервера.
- Перезапустите сервер.

Клиентская копия JAR встроена непосредственно в `MineLauncher.exe`. Перед
каждым стартом лаунчер заново проверяет и при необходимости восстанавливает
её в `mods`, поэтому обновление, удаление или полная переустановка сборки не
требует добавлять мод вручную. Сам NeoForge загружает моды только из игровой
папки `mods`, поэтому встроенный JAR всё равно временно появляется там.

Если серверная часть мода не установлена, игра продолжит работать, но
выбранный скин не будет синхронизирован, а клиент покажет уведомление.

## Ограничения и хранение

- Поддерживаются современные PNG-скины строго 64×64 и размером не более
  256 КиБ.
- Индексированные, grayscale, RGB и RGBA PNG принимаются лаунчером и перед
  запуском автоматически преобразуются в безопасный 8-битный RGBA PNG,
  одинаково читаемый клиентом и сервером.
- Для локального файла интернет-сервис загрузки скинов не используется.
- HTTPS-ссылку загружает сам лаунчер перед стартом игры.
- Сервер хранит скины подключённых игроков в памяти. После каждого входа
  клиент отправляет выбранный скин заново.

## Пересборка мода

Запустите `client-mod/build.ps1`. Gradle Wrapper скачает нужную версию Gradle,
соберёт мод и заменит JAR в папке `assets`.
